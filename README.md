## 分类方法

1. **名称优先匹配**：先匹配 repo 名称中的关键词
2. **描述关键词匹配**：再匹配描述中的关键词
3. **层级分类**：使用 `Domain/Subcategory` 命名（如 `AI/LLM/Agent`）
4. **版本迭代**：V17 → V24，每版在前版基础上增加更广泛的模式
